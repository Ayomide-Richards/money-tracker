# Money Tracker 💰

A clean, fast, and responsive Money Tracker web application built with vanilla HTML, CSS, and JavaScript. It runs entirely in the browser with no backend, server, or database required—all transactions are saved locally via `localStorage` so your data persists across page reloads.

## ✨ Features

- **Add Transactions**: Track income and expenses with an amount, transaction type, and description.
- **Top Summary & Counter**: See the total number of transactions right at the top, along with live Net Balance, Total Income, and Total Expense cards.
- **Edit & Update**: Seamlessly edit any transaction in-place.
- **Delete with Confirmation**: Safeguarded against accidental deletion with a clean confirmation dialog.
- **Instant Search**: Real-time filtering across descriptions, amounts, and transaction types.
- **Friendly Empty States**: Clean illustration states for when no transactions exist or when search results return empty.
- **Mobile-First Design**: Optimized for mobile screens, tablets, and desktops with accessible, touch-friendly tap targets.
- **Offline & Private**: 100% client-side. No sign-up, login, or external server calls.

## 🚀 Getting Started

No build tools, package managers, or servers are needed.

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Ayomide-Richards/money-tracker.git
   ```
2. Open `index.html` in any modern web browser:
   - Double-click `index.html`, or
   - Right-click and choose **Open with** &rarr; Chrome / Edge / Firefox / Safari.

## 🛠️ Built With

- **HTML5**: Semantic markup and accessible form elements.
- **CSS3**: Modern CSS custom properties (variables), Flexbox, CSS Grid, and responsive media queries.
- **Vanilla JavaScript (ES6+)**: DOM manipulation, event delegation, and Web Storage API (`localStorage`).
